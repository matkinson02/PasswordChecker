# PasswordChecker
This is a simple Python program to test password strength and provide feedback to the user.

Password scores are calculated based on uppercase and lowercase letters, number of digits, and special characters.

I used this [tutorial](https://dev.to/immah/building-a-password-strength-checker-in-python-47om) and this [list](https://github.com/danielmiessler/SecLists/blob/master/Passwords/Common-Credentials/100k-most-used-passwords-NCSC.txt) of commonly used passwords.

I improved upon the source code from the tutorial by enhancing clarity/readability of comments and password feedback to user.

## Files
The project consists of the following files:
* passwordchecker.py: Python file containing the password checker program.
* common_passwords.txt: Text file containing a list of 100,000 of the most used passwords.
* README.md: Readme file with context and instructions.
